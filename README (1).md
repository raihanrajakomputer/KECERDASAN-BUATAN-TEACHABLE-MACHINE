# Deteksi Jari 5 atau 3

Proyek computer vision untuk mengenali pose **lima jari** atau **tiga jari** lewat webcam.
Model dilatih memakai Teachable Machine dan dijalankan dengan TensorFlow.js langsung di browser.

## Demo
https://raihanrajakomputer.github.io/kecerdasanbua/

## Cara menjalankan
1. Buka link demo di Chrome atau Edge.
2. Tekan "Mulai Kamera" dan izinkan akses kamera.
3. Tunjukkan telapak tangan ke kamera.

## Isi repo
- `index.html` : halaman web dan kode program
- `model/` : model hasil latihan Teachable Machine (`model.json`, `metadata.json`, `weights.bin`)

## Teknologi
HTML, JavaScript, TensorFlow.js, Teachable Machine
